# SKinny Editor 0.3.0-preview.1 — First Public Preview

SKinny Editor is a visual editor for StereoKit. This first public preview is
intended for developers who want to try the current visual-authoring workflow,
build sample content, and help shape project onboarding.

> This is a pre-release. Scene, protocol, and adapter contracts may change
> before a stable release.

## Download and run

1. Download `SKinny-Editor-0.3.0-preview.1-win-x64.zip` below.
2. Optionally verify it using the adjacent `.sha256` file.
3. Extract the ZIP to a user-writable directory.
4. Run `SKinny.Editor.exe`.
5. Open the bundled `examples\HelloEditor\HelloEditor.skproject.json` project
   for the fastest first run.

The editor is self-contained and does not require a separately installed .NET
desktop runtime. Building the bundled example or another StereoKit project
requires a compatible .NET SDK and any workloads required by that project.

The executable is not code-signed yet, so Windows may display a trust or
SmartScreen warning. Verify that the archive came from this release page and
review the checksum before running it.

## Highlights

- Resizable Hierarchy, Scene, Inspector, Project, and Console panels
- Separate Scene and Game workflows
- Child objects, multi-selection, rename, duplicate, delete, undo, and redo
- Move, Rotate, and Scale tools with camera controls and snapping
- GLB, texture, image, material, font, text, Quad, and spatial UI authoring
- Project-owned components with generated Inspector presentations
- Workspace trust, crash recovery, and isolated runtime processes
- Bundled example project and four matching editor SDK packages

## Known limitations

- This release is an unsigned portable Windows x64 ZIP, not an installer.
- There is not yet a complete Project Hub or new-project wizard.
- Existing projects use the descriptor and runtime-adapter onboarding flow.
- Arbitrary procedural objects created only by project code may remain opaque
  to the editor.
- Hardware-specific DPI, GPU, device-loss, and headset coverage is still
  expanding.
- A future macOS edition may share the scene, adapter, and asset formats, but
  no macOS binary is included in this release.

## Verify the download

From PowerShell in the download directory:

```powershell
$expected = (Get-Content .\SKinny-Editor-0.3.0-preview.1-win-x64.zip.sha256).Split()[0]
$actual = (Get-FileHash .\SKinny-Editor-0.3.0-preview.1-win-x64.zip -Algorithm SHA256).Hash
$expected -eq $actual
```

The command should return `True`.

Please report reproducible problems through the
[GitHub issue tracker](https://github.com/mr0ng/skinny-editor/issues), including
the editor version, project type, and relevant Console diagnostics.
